# 🎮 DEADZONE RUNNER - Premium Mobile Lane Runner Survival Game

**Production-Ready Game Specification & Implementation Guide**  
*A polished, monetizable mobile game designed for iOS & Android via Unity*

## 📋 PROJECT OVERVIEW

DEADZONE RUNNER is a premium lane-runner survival game combining fast-paced arcade action with deep progression systems. The game features:

- **3-Lane Auto-Running** with smooth swipe transitions (150ms)
- - **5 Game Modes**: Campaign (100+ levels), Endless, Daily Challenges, Boss Rush, Timed Events
  - - **12+ Unique Heroes** with stat progression and special abilities
    - - **6 Weapon Types** with upgrade trees and attachment systems
      - - **Monetization** optimized for 30-40% conversion while maintaining 70%+ F2P playability
        - - **Target**: 60FPS on mid-range devices, all screen sizes

          ## 🎯 CORE GAMEPLAY LOOP (BUILD PRIORITY 1)

          ### Lane System
          ```
          Player Hero (center)
          ━━━━━━━━━━━━━━━━━━━━━
            LANE 1  |  LANE 2  |  LANE 3
          ━━━━━━━━━━━━━━━━━━━━━
          (Enemies approach from top)
          ```

          **Mechanics:**
          - Auto-run forward at increasing speed
          - - Auto-fire bullets at enemies in current lane
            - - **Swipe left/right** to switch lanes (150ms animation)
              - - **Tap** special ability (hero-dependent, cooldown-based)
                - - **Double-tap** grenade/AOE attack (consumable resource)
                 
                  - ### Combat Feel (CRITICAL)
                  - - Screen shake on hit (~5 pixels, 100ms duration)
                    - - Enemy flash on damage (white tint, 50ms)
                      - - Particle effects on hit (projectile burst)
                        - - **Combo System**: 5 kills = 2x score, 10 kills = 3x score
                          - - **Critical Hits**: 15% base, visual effect (red glow + boom)
                            - - **Bullet Time**: near-miss enemies trigger 0.5x slow-mo (2 sec duration)

                              ## 🎮 5 GAME MODES

                              ### 1. CAMPAIGN MODE (100+ Levels)
                              ```
                              10 Chapters × 10 Levels/Chapter
                              Environments: City → Desert → Forest → Snow → Volcano → Wasteland →
                                           Underwater → Sky → Void → Apocalypse
                              ```

                              **Features:**
                              - 3-star rating system (performance-based)
                              - - Boss fight every 10th level
                                - - Story cutscenes between chapters
                                  - - Rewards: Coins (100-500), Gems (0-5), Hero Shards (0-2), Weapon Parts
                                    - - Level difficulty scales logarithmically
                                      - - Unlock next chapter at 5+ stars on previous levels
                                       
                                        - **Level Parameters Example:**
                                        - ```
                                          Level 1: 3 Walkers, 2 Runners, 30s duration, 50 coins reward
                                          Level 10: Boss fight, complex pattern, 500 coins + 5 gems
                                          Level 100: 15 enemies/wave, 5 waves, Overlord boss, 10000 coins
                                          ```

                                          ### 2. ENDLESS SURVIVAL MODE
                                          - Infinite waves with global leaderboards
                                          - - Difficulty scales per wave (+5% health, +3% damage)
                                            - - Weekly leaderboard resets (top 100 get rewards)
                                              - - Exclusive "Endless-Only" power-ups
                                                - - Milestone rewards: 1km = 10 gems, 5km = 50 gems, 10km = hero shard
                                                 
                                                  - ### 3. DAILY CHALLENGE MODE
                                                  - - 3 unique challenges per day (reset at midnight UTC)
                                                    - - Modifiers: 2x enemies, no power-ups, speed-run timer, permadeath
                                                      - - Tiered rewards: Bronze (50 coins), Silver (100 coins), Gold (200 coins + gem)
                                                        - - Bonus: Complete all 3 = extra gem chest
                                                         
                                                          - ### 4. BOSS RUSH MODE (Unlocked after Ch. 3)
                                                          - - Fight 10 bosses back-to-back with 10 second breaks
                                                            - - Timer-based scoring (faster = higher rank)
                                                              - - Weekly rotating boss lineup
                                                                - - Leaderboards per week
                                                                  - - Rewards based on damage dealt
                                                                   
                                                                    - ### 5. EVENTS MODE
                                                                    - - Limited-time themed events (Halloween, Christmas, New Year)
                                                                      - - Event currency (different per event)
                                                                        - - Event shop with exclusive heroes/skins
                                                                          - - Event leaderboards
                                                                            - - Auto-expires after 7-14 days
